# 关键实验结论（速览）

均在同一台 x86（RTX PRO 6000 96GB, torch 2.8.0+cu128）上完成。

## 1. K=25 vs K=50 同机配对

**方法**：固定 checkpoint、精度、采样设置，只改变执行长度 K。选 16 个最难任务，K=25 与 K=50 各跑 50 个种子，取两边实际种子交集（平均每任务 46 个，共 744 个配对回合）。

| setting | K=25 | K=50 | 差 | McNemar（25赢/50赢/平） | 显著性 |
|---|---|---|---|---|---|
| clean | 54.84% | 55.51% | −0.67pp | 86 / 91 / 567 | χ²=0.09，不显著 |
| randomized | 23.79% | 19.76% | **+4.03pp** | 78 / 48 / 618 | χ²=6.67，**p<0.05** |

**结论**：clean 无差异；randomized 上 K=25 显著更优。与上一版在 GH200 上的独立配对实验（randomized +4.5pp）一致。

## 2. 三方对比与效应分解（16 难任务）

| | clean | randomized |
|---|---|---|
| K=25（本机 x86） | 54.88% | 24.09% |
| K=50（本机 x86） | 55.51% | 19.85% |
| 上一版提交（GH200, K=50） | 44.38% | 20.81% |
| **K 效应**（K25 − K50，同机） | −0.64pp | **+4.24pp** |
| **环境效应**（K50 x86 − GH200） | **+11.14pp** | −0.97pp |

**结论**：clean 的差距主要来自评测平台（aarch64 Vulkan 渲染路径），randomized 的环境差异几乎为零；K=25 的收益集中在 randomized。

## 3. 评测环境一致性校准

用官方发布权重 `robbyant/lingbot-vla-v2-6b-robotwin`（配官方 `robotwin.yaml` + `robotwin.json` 归一化统计）在本机跑 6 个任务，平均约 **80%**，与官方公布的 x86 基准 83.5% 相差 3.2pp 以内，说明本机评测环境与官方标准一致。

> 该校准仅用于环境验证；该权重未作为训练起点、未用于蒸馏、未参与本提交权重的任何训练环节（规则 3.2/3.5）。

## 4. 风险披露

- clean 上 `open_microwave`（1500 步长程任务）在 K=25 下从 93.8%（K=50）降至 43.8%，是明确退化；同期 `move_can_pot`（+27.1pp）、`blocks_ranking_size`（+8.7pp）、`place_a2b_right`（+8.2pp）、`handover_block`（+6.1pp）等提升，总体打平。
- randomized 侧无任何任务下降超过 20pp。
